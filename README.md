# STM32F103 MPU6050 Async Driver (Bare-Metal State Machine)

Повністю асинхронний, неблокуючий драйвер для шестиосьового інерційного датчика **MPU6050** (I2C адреса `0x68`), розроблений для інтеграції в систему керування колісного робота на базі мікроконтролера **STM32F103C8T6 (Blue Pill)**. 

Проєкт є частиною переходу від RTOS-архітектури (ESP32) до архітектури чистих скінченних автоматів (**State Machine**) на STM32 для забезпечення максимальної швидкодії, точних таймінгів та нульового блокування процесора.

## 🚀 Ключові особливості драйвера

- **Нуль блокуючих циклів (`while`)**: Ініціалізація датчика виконується через переривання (`IT`), а постійне пакетне зчитування 14 байт даних (акселерометр + температура + гіроскоп) — через **I2C DMA**. Процесор повністю вільний під час транзакцій шини.
- **Мікросекундний хронометраж**: Для інтегрування кутової швидкості ($\Delta Angle = Gyro \times dt$) використовується апаратний 16-бітний таймер (`TIM2`) з дискретністю **1 мікросекунда**, що зводить математичну похибку округлення часу до нуля.
- **Робототехнічна координатна сітка**: Знак кутової швидкості інвертовано, а підсумковий кут `ANGLE_Z` нормалізовано у формат **`0.0° ... 360.0°` із накопиченням за годинниковою стрілкою** (0° — Північ, 90° — Схід), що ідеально підходить для алгоритмів побудови карти (A*, лідари).
- **Динамічне автокалібрування**: При старті системи драйвер автоматично збирає 500 точок у статичному стані для точного визначення апаратного зміщення нуля (Zero-rate offset) осі Z.
- **Сумісність з Fast Mode**: Драйвер протестований та стабільно працює на розігнаній шині **I2C (400 kHz)** спільно з іншими асинхронними датчиками (VL53L0X, HP5883).

## 🛠 Апаратна конфігурація (STM32CubeIDE)

- **SYS**: Debug -> Serial Wire
- **RCC**: HSE -> Crystal/Ceramic Resonator (HCLK = **72 MHz**)
- **I2C1**: Fast Mode (**400,000 Hz**), виводи `PB6 (SCL)`, `PB7 (SDA)`.
  - *NVIC*: Увімкнено `I2C1 event interrupt` та `I2C1 error interrupt`.
  - *DMA*: Додано потік **`I2C1_RX`** (Direction: Peripheral to Memory, Mode: Normal, Increment Address: Memory, Data Width: Byte).
- **TIM2**: Internal Clock. 
  - `Prescaler (PSC)` = `72 - 1` (частота рахунку 1 MHz = 1 мкс).
  - `Counter Period (ARR)` = `65535` (максимальний період, обробка переповнення реалізована в драйвері).
- **USART1**: Asynchronous, 115200 bits/s, 8 Bits, N, 1 (`PA9 TX`, `PA10 RX`) — для виведення дебагу.

## 📊 Результати тестів (у статиці та динаміці)

При калібруванні датчик демонструє високу стабільність:
- **Зміщення нуля (Offset Z)**: `~ -14 LSB`.
- **Дрейф у спокої**: Кут `ANGLE_Z` фіксується на `0.00 deg` і не пливе завдяки налаштованому апаратному фільтру низьких частот MPU6050 (DLPF = 42 Hz).
- **Точність інтегрування**: При фізичному повороті плати на 90° по кутнику, драйвер демонструє реальне значення `90.27°` (похибка менше 0.3%).

## 📁 Структура та архітектура драйвера

### Скінченний автомат (`mpu6050.h`)
Драйвер керується переліком станів `MPU_State_t`:
```c
typedef enum {
    MPU_STATE_UNINIT = 0,
    MPU_STATE_INIT_PWR,       // Пробудження + вибір джерела тактування (Gyro X)
    MPU_STATE_INIT_CONFIG,    // Налаштування DLPF (42 Hz)
    MPU_STATE_INIT_GYRO,      // Вибір шкали гіроскопа (±500 °/s, чутливість 65.5 LSB)
    MPU_STATE_INIT_ACCEL,     // Вибір шкали акселерометра (±8g, чутливість 4096 LSB)
    MPU_STATE_READY,          // Дані готові / Датчик очікує наступного такту
    MPU_STATE_READING_DATA,   // Триває асинхронне читання 14 байт по DMA
    MPU_STATE_ERROR           // Обробка помилок шини
} MPU_State_t;
```

### Основні функції API

1. **`MPU6050_Init_Async(...)`** — Ініціалізує дескриптор пристрою, прив'язує апаратну периферію I2C, таймер TIM2 та запускає лічильник мікросекунд.
2. **`MPU6050_Process_State(...)`** — Головне серце драйвера. Викликається в суперциклі `while(1)`. Перевіряє прапорець зайнятості шини й асинхронно крокує по станах конфігурації.
3. **`MPU6050_Calibrate_Gyro_Z(...)`** — Блокуюча функція (використовується тільки при старті), яка накопичує масив сирих даних для зрізання постійної похибки нуля гіроскопа.
4. **`MPU6050_Update_Angle(...)`** — Викликається після завершення DMA-транзакції. Розраховує реальне $dt$, переводить сирі Big-Endian дані з буфера в градуси за секунду, інтегрує кут і нормалізує його в межі `0...360°`.

## ⚙️ Порядок інтеграції в `main.c`

1. У секції `USER CODE 4` перенаправити HAL-коллбеки завершення транзакцій у драйвер:
   ```c
   void HAL_I2C_MemTxCpltCallback(I2C_HandleTypeDef *hi2c) {
       if (hi2c == hmpu1.hi2c) MPU6050_I2C_MemTxCpltCallback(&hmpu1);
   }
   void HAL_I2C_MemRxCpltCallback(I2C_HandleTypeDef *hi2c) {
       if (hi2c == hmpu1.hi2c) MPU6050_I2C_MemRxCpltCallback(&hmpu1);
   }
   ```
2. У `USER CODE 2` запустити ініціалізацію та автокалібрування:
   ```c
   MPU6050_Init_Async(&hmpu1, &hi2c1, &htim2);
   while (hmpu1.state != MPU_STATE_READY) MPU6050_Process_State(&hmpu1);
   MPU6050_Calibrate_Gyro_Z(&hmpu1, 500);
   ```
3. У головному циклі `while(1)` піднімати прапорець читання `MPU_STATE_READING_DATA` з необхідною частотою (рекомендовано 50 Hz, тобто кожні 20 мс).
